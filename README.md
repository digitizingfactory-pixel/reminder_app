# Desktop Reminder App

A tiny desktop reminder app made with Python + Tkinter.

## What it does
- Lets you enter a date/time and reminder text.
- Shows upcoming reminders in a list.
- Rings (`bell`) and pops up a message when the reminder time is reached.

## Run it
1. Make sure you have Python 3 installed.
2. Run:

```bash
python3 reminder_app.py
```

## Date format
Use this exact format when adding reminders:

```text
YYYY-MM-DD HH:MM
```

Example:

```text
2026-02-23 14:30
```
